Daily tracking of Resin regeneration and Primogem use. Honestly just trying to help new players enjoy playing without a million guides 😺 just a quick script to help handle those annoying parts. 

<img width="513" height="514" alt="gencat" src="https://github.com/user-attachments/assets/8e16f4c1-9147-46c2-b2af-30e1fbcaeb0e" />

Basically, its a simple tool to keep track of your resources so you don't need to jump mental hurdles. 
  * Resin Timer: Script checks last time you opened it and calculates how much you regenerated (approx 1 every 8 min)
  * Primogem Goal: If you are saving for a specific character, you can set a goal to see the % and how close you are
  * Savs the data to a ```.json```

1. Download the files
2. Open the terminal/command prompt
3. Run:
   ```python tracker.py```
4. Follow the menu to update Resin or Gems
